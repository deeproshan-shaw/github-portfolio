# github-portfolio

This repository contains a static portfolio for Deeproshan Shaw that reads profile data from `profile.json` and renders GitHub repositories automatically.

Files:
- `index.html` — main page
- `styles.css` — styling
- `script.js` — loads `profile.json` and GitHub repos
- `profile.json` — your profile data (provided)
- `favicon.svg` — favicon

How to use
1. Ensure `profile.json` is present in the repository root (it is included here).
2. Open `index.html` locally or push to GitHub and enable GitHub Pages (Settings → Pages → select branch `main` and root).
3. The site will display your profile information automatically. If you want to show a different GitHub account, set the `data-username` attribute on the `<html>` tag or add `"github": "yourusername"` to `profile.json`.

Customizing
- Edit `profile.json` to change text, add/remove experience entries, skills, certifications, etc.
- Modify styles in `styles.css` for visual changes.
